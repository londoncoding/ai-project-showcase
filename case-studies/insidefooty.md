# InsideFooty · Passion project

An independent passion project: a grassroots football player-development application.

![InsideFooty — actual product screenshot](https://mark-north-portfolio.vercel.app/assets/03ae06811c939cb0.png)

## The problem

Grassroots football needs useful development information for coaches, parents and players, with careful control over who can access information about young players.

## My contribution

I built the application through AI-assisted development, typically using Claude Code and Codex. The work includes parent-controlled player access, role-based controls and supporting access-control test scripts.

## Design and implementation decisions

- Make access relationships explicit rather than rely on interface visibility.
- Treat parent and coach access as part of the product design.
- Use access-control test scripts, including a coach-removal scenario.

## Evidence

The screenshot shows the actual InsideFooty website. The existence of access-control tests is not a claim of an independent security audit.
